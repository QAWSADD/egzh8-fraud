# ЕГЖ‑8 · Карта транзакцияларындағы алаяқтықты анықтау

Бұл оқу жүйесі төлем операциясын тексеру үшін сараптамалық ережелер мен бинарлық жіктеу моделін біріктіреді. Браузерде төрт мысал дайын. Қалыпты операция, шекке жақын жағдай, күмәнді операция және мүмкін емес сома. Сайт орысша ашылады, қазақшаға **ҚАЗ** батырмасы ауыстырады.

## Windows жүйесінде ашу

Осы компьютерде **START.cmd** файлын ашыңыз. API мен сайт бірге бір жергілікті мекенжайда жұмыс істейді.

- Сайт: http://127.0.0.1:8038/
- Swagger: http://127.0.0.1:8038/docs
- API күйі: http://127.0.0.1:8038/health
- Тесттер: **TEST.cmd**

Басқа компьютерде, Python 3.10+ орнатылған кезде, үш команда жеткілікті. Екінші және үшінші команданы екі бөлек терминалда орындаңыз.

```text
python -m pip install -r requirements.txt
python -m uvicorn api.main:app --host 127.0.0.1 --port 8038
python app/ui.py
```

Дайын модель ZIP ішінде бар. Демонстрация үшін үлкен CSV жүктеу қажет емес.

## Деректер және оқыту

[Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) · MLG‑ULB және Worldline. 2013 жылғы қыркүйектегі екі күн, 284 807 операция, 492 алаяқтық (0,1727%). Бастапқы файлдың SHA‑256 мәні `data/source.json` ішінде. CSV мұрағатқа қосылмаған.

```text
python data/download.py
python train.py
python -m pytest -q
```

Kaggle автоматты жүктеуі қолжетімсіз кезде ресми беттен архивті алып, `creditcard.csv` файлын `data/` каталогына салыңыз. Ноутбук `notebooks/eda_model.ipynb` сақталған графиктерді және есептелген нәтижелерді ашады. Модель үш алгоритмнің 5 уақыттық фолдтағы нәтижесімен таңдалды. Гиперпараметрлер тек train ішінде салыстырылды. Калибрлеу, шек таңдау және соңғы тест жеке уақыт аралықтарында өтті.

### Соңғы тест

| Көрсеткіш | Мән |
| --- | ---: |
| Average Precision | 0,7777 |
| Recall | 0,7568 |
| Precision | 0,6588 |
| TP / FP / FN / TN | 56 / 29 / 18 / 56 643 |
| Таңдалған порог | 0,03665 |

Тестте 56 746 операция және 74 алаяқтық бар. Порогты таңдауда 1 өткізіп алудың құны 25 жалған дабылға тең деп алынды. Бұл оқу моделінің салыстырмалы шығын бірлігі. Метрикалар ережелер қолданылмай тұрған модельге қатысты.

## API

| Маршрут | Нәтиже |
| --- | --- |
| `POST /predict` | Шешім, модель бағасы және іске қосылған ережелер |
| `POST /explain` | Шешім және ең ықпалды бес белгі |
| `GET /health` | Модель және таңдалған порог |
| `GET /examples` | Төрт оқу мысалы |
| `GET /metrics` | Тест метрикалары, PR қисығы және матрица |

`amount` — деректер жиынындағы өлшеммен берілген сома. `time` — бірінші операциядан кейін өткен секунд, сағат белдеуі бар уақыт емес. `components` — V1–V28 ретіндегі массив. Кемінде 21 мән болса, бос тұрған компоненттер train медианаларымен толтырылады. `count_10m` ағымдағы операцияны қамтиды. Жиілік, алдыңғы операциядан өткен уақыт және бақылау тізімі бөлек берілетін оқу контексті. Ашық жиында карта идентификаторы мен осы контекст жоқ.

`clear` — сигнал жоқ, `review` — қолмен тексеру, `flagged` — күмәнді, `invalid` — қате кіріс (HTTP 422). Егер ереже модельді аттап өтсе, `probability` бос. API әр сұраудың уақытын, рұқсат берілген параметрлерін және шешімін `logs/decisions.sqlite` ішіне жазады. Жолды `FRAUD_LOG` айнымалысымен өзгертуге болады. Карта нөмірі және басқа төлем деректемелері енгізілмейді.

## Қорғауға қысқа сценарий

1. Сайттағы **Обычная**, **На границе** және **С ошибкой** мысалдарын басыңыз. Шешім мен ереженің кодын көрсетіңіз.
2. **Подозрительная** мысалын ашып, `R14` және ең әсерлі белгілерді көрсетіңіз. `/explain` арқылы сол деректерді Swagger-де жіберіңіз. Дайын параметрлер `data/demo_cases.json` ішінде.
3. Қалыпты мысалды қайта таңдап, **Дополнительные данные** ішіндегі оқу бақылау тізімі жалаушасын қосыңыз. **Проверить операцию** батырмасын басыңыз. Ереже `R9` бірінші іске қосылады, модель бағасы көрсетілмейді.
4. Өзгеріс сұрағына дайындық. `src/rules.py` ішінде ережені қосыңыз, `tests/test_system.py` ішінде белгілі кіріс үшін нәтижені тексеріңіз және **TEST.cmd** арқылы іске қосыңыз.

Негізгі материалдар: `report.docx`, `notebooks/eda_model.ipynb`, `results/metrics.json`, `results/figures/`, `src/rules.py`, `src/decision.py`.
